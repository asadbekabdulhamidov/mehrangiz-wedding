# Asadbek & Mehrangiz — To'y Taklifnomasi (Dark-Luxe Wedding Invitation)

Dark-luxe uslubidagi (issiq sham shu'lasi, oltin jilosi, suzuvchi uchqunlar va glassmorfizm) dabdabali to'y taklifnomasi veb-sayti.

## 🌟 Asosiy Xususiyatlar:
1. **Kinematik Hero Section**:
   - Fon suratida mayin Ken Burns nafas olish animatsiyasi.
   - Oltin jilosidagi kalligrafik nomlar: **Asadbek & Mehrangiz**.
   - Jonli va aniq Countdown (kun, soat, daqiqa, soniya) taymeri.
   - "Taklifni tasdiqlash" va "Taqvimga saqlash" tezkor tugmalari.

2. **Musiqa Pleyeri (HTML5 Audio)**:
   - Pastki o'ng burchakdagi suzuvchi shaffof pleyer.
   - Jonli ovoz to'lqini (Equalizer soundwave) animatsiyasi.
   - Brauzer cheklovlariga qarshi avtomatik ijro (birinchi bosishda yoki tugma orqali) va ovoz yumshoq ko'tarilishi.

3. **Fotogalereya & Lightbox**:
   - Kelin-kuyovning FHDYO va guldasta bilan tushgan haqiqiy fotosuratlari.
   - Har bir suratni bosganda to'liq ekranda ochiladigan Lightbox modali.

4. **To'y Dasturi (Vertikal Taymlayn)**:
   - 17:00 dan 22:30 gacha bo'lgan tantanali marosimlar bosqichlari (Kelin tushdi, Nikoh oqshomi, Show dastur, To'y torti).

5. **Manzil va Joylashuv**:
   - To'yxona nomi va manzili.
   - 1-bosishda **Google Xarita** va **Yandex Xarita**da ochish.
   - **Google Calendar** va **Apple/Outlook iCal (.ics)** formatida taqvimga yuklab olish.

6. **RSVP — Taklifni Tasdiqlash & Tilaklar Kitobi**:
   - Mehmon ismi, qatnashish holati ("Boraman" / "Bora olmayman"), mehmonlar soni va tilaklar.
   - Yuborilganda zarhal oltin mushakbozlik (confetti) effekti.
   - Javoblar saqlanib, "Mehmonlar tilaklari" doskasida aks etadi.
   - Javobni darhol Telegram orqali yuborish imkoniyati.

7. **Open Graph & Ijtimoiy Tarmoqlarda Ulashish**:
   - Telegram, WhatsApp, Instagram'da havola yuborilganda chiroyli rasm, sarlavha va sana bilan ko'rinadi.

---

## 🚀 Qanday ishga tushiriladi?

Loyihani ishga tushirish uchun quyidagi buyruqni bering:

```bash
# Rivojlanish rejimida ishga tushirish (Hozir ishlayapti)
npm run dev

# Saytni to'liq production formatida yig'ish (dist/ papkasiga)
npm run build
```

- **Lokal havola**: [http://localhost:5173/](http://localhost:5173/)
- **Telefon orqali ko'rish**: Bir xil Wi-Fi ga ulangan holda terminalda chiqqan Network havolasini oching (masalan, `http://172.20.10.5:5173/`).
